# Pangasinan Website Booking System

This responsive web application was originally developed as a Group 2 Final Activity Project in **Oracle Programming II** at ACLC College of Manila. It serves as a comprehensive tourism hub where users can explore local history, discover top travel destinations, and seamlessly book tickets before traveling to Pangasinan, Philippines.

## 🛠️ Tech Stack & Features

* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **UI Libraries:** Swiper.js (Touch-friendly interactive carousels), FontAwesome
* **Database & Backend:** 
  * *Legacy Architecture:* PHP & SQL (Original academic submission)
  * *Modernized Architecture:* Web3Forms API (Serverless form handling for static deployment)
* **Core Features:** 
  * User ticket reservation inquiries and travel management for Pangasinan tours.
  * Fully responsive design utilizing CSS Flexbox for cross-device compatibility.
  * Dynamic destination showcases, client review sliders, and structured historical timelines.
